Privacy Policy

Last updated: 2026-11-10

1. Who operates this tool

"Shutten Data Lab Uploader" (the "Tool") is a personal software tool built and operated by a single individual (the "Operator") for the Operator's own content channel, Shutten Data Lab. The Tool is used only by the Operator, only with the Operator's own TikTok account (@shutten_data_lab). It is not a public service and has no other users.

2. What data the Tool handles

  • OAuth tokens. When the Operator authorizes the Tool through TikTok Login Kit, TikTok issues an access token and a refresh token for the Operator's own account. These tokens are stored locally, on the Operator's own computer, and are used only to call TikTok APIs on the Operator's behalf.
  • Basic account information. Through the user.info.basic scope, the Tool can read the Operator's own TikTok open ID and display name, used only to confirm that the correct account is connected.
  • Video files. The Tool uploads video files that the Operator produced himself to the Operator's own TikTok account as drafts.

3. What the Tool does not do

  • It does not collect data about any person other than the Operator.
  • It does not sell, rent, or share any data with third parties.
  • It does not use cookies, analytics, advertising, or tracking of any kind.
  • It does not store any data on external servers; the tokens and files remain on the Operator's own computer and on TikTok's platform, per TikTok's own policies.

4. Deleting the data

The Operator can revoke the Tool's access at any time in TikTok's settings (Manage connected apps), which invalidates the tokens. Deleting the locally stored token files on the Operator's computer removes the remaining data completely.

5. Changes

This policy may be updated when the Tool changes. The current version will always be available at this URL.

6. Contact
